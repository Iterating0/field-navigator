# Field Navigator 科研领域导航器

Field Navigator帮助学生进入陌生科研领域：从一个明确的研究主题出发，找到前置知识、研究分支和可追溯的论文阅读起点。参赛团队使用中性名称FieldLab；公开代码、介绍和演示材料不含参赛者姓名、学号、手机号或个人邮箱。

## 解决的问题

文献检索通常返回平铺的论文列表，初学者仍需判断先学什么、哪些方向值得深入、推荐理由依据什么。Field Navigator把检索结果组织成可继续探索的领域图谱，并将领域关系连接到支持论文。

## 当前可运行能力

- 输入明确的领域名称，从OpenAlex获取候选论文。
- 大模型生成前置领域、研究分支与论文评价，结构化输出经过校验。
- 关系详情可展开支持论文的标题与链接，包括未进入核心论文列表的证据。
- 分阶段展示候选论文、领域地图和最终排序；可取消分析、继续探索分支和导出完整JSON。
- 本地SQLite缓存完整结果与已成功的分析阶段，失败不会覆盖已有完整结果。

论文ID校验只证明来源属于本次候选集，不证明论文在语义上充分支持模型生成的关系。模型置信度未经概率校准，排序是候选集中的启发式推荐。输入歧义简称仍需用户提供更明确的领域名称。

## 演示方式

离线演示路径为NHSE → Incoherent NHSE → Photonic quantum walks。根领域默认展示8篇核心论文、4个研究分支，数据来自已核对的内置书目。离线模式不调用外部模型，界面明确标为预设演示。

真实AI分析须同时配置论文检索服务及兼容Chat Completions的模型服务，或使用OpenAlex的可用匿名配额。没有模型key时，非预设领域仅展示论文，不编造研究分支。实时模式会向检索服务发送领域词，并向模型服务发送领域词及候选论文元数据和摘要。

## 最小演示顺序

1. 用NHSE离线演示解释领域图谱、前置知识与研究分支。
2. 展开一条关系的支持论文，打开原始来源，说明证据边界。
3. 进入研究分支，返回已有结果，再导出JSON。
4. 用一个明确领域做真实分析，展示论文来源与AI分析标识；外部服务失败时保留错误与演示模式的区别。

仓库没有PDF解析、RAG问答、自动综述或完整的简称澄清功能。参赛介绍只描述以上已实现能力，性能数字以实际验证记录为准。

## 本次本地验证

2026年10月13日，60项后端测试、6项前端测试与生产构建通过。单进程预览的首页、健康接口和离线演示已验证；浏览器中已验证关系支持论文可以展开，并含可访问的来源链接。

真实OpenAlex与大模型链路完成了二维电子气分析：40篇候选、8篇核心论文、5个前置领域、7个研究分支、20篇关系证据论文，所有关系ID都对应论文元数据。本次完整请求约16.94秒；这是一次运行记录，尚未进行学术质量人工评测，不作为速度或准确率保证。

ModelScope配置和本机HTTP检查已通过。[GitHub Actions](https://github.com/Iterating0/field-navigator/actions/runs/38343337727)已完成后端测试、前端测试与生产构建，以及原应用和扁平上传包的Docker镜像构建。云端部署和运行验证仍待完成。本机Docker Desktop启动时出现推理服务套接字错误，没有重置Docker或删除数据。
